Dit is een console applicatie, dus **geen WPF.**

In **Domain** vind je enkel de `Fish.cs` class.

In I**nfrastructure** een `List<>` van verschillende Fish.

Hier moet je verder niet naar kijken.

In Program.cs wordt de hele vissenrepo binnengehaald.  Voer je LINQ queries uit op fish (of je eigen gefilterde lists).
